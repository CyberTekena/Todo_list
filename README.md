# Vanilla JavaScript Task List

A browser task-list exercise built with HTML, CSS, and JavaScript.

## Features

Add nonempty tasks, toggle their completed appearance by clicking the task, and hide tasks with the remove button. State lives in the DOM and is lost when the page reloads.

## Run

Open [index.html](index.html) in a browser, or serve the repository with `python -m http.server 8000` and open http://localhost:8000.

## Structure

- [index.html](index.html) — page markup.
- [script.js](script.js) — task creation and event handlers.
- [style.css](style.css) — presentation.

## Next improvements
